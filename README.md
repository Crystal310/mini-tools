# mini-tools

小测试 / H5 小工具合集，每个子文件夹是一个独立的静态页面，通过 GitHub Pages 直接访问。

## 已上线

- [history-figure-quiz](./history-figure-quiz/) — 你是哪位历史名人：12题性格测试，[在线体验](https://crystal310.github.io/mini-tools/history-figure-quiz/)

## 新增一个测试

1. 新建子文件夹，放入 `index.html`（单文件，内联所有 CSS/JS）
2. push 到 main 分支，GitHub Pages 会自动更新
3. 访问地址为 `https://crystal310.github.io/mini-tools/<文件夹名>/`
